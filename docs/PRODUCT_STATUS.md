# StdHub 产品状态

> 最后核对：2026-08-10 · 基线 v1.4.17

| 功能 | 当前状态 | 用户可见行为 | 生产门禁 |
|---|---|---|---|
| BZ/GBW/BY 标准搜索下载 | 可用 | 多源搜索、下载、自动入库、预览 | 高成本接口限流、下载完整性校验 |
| Labr 补给源 | 可用但受上游额度限制 | 主动搜索和下载，不参与默认精确搜索 fallback | 登录/额度错误独立处理 |
| CNAS/CMA 实验室资质 | 可用 | 本地订阅、同步、搜索和徽章 | 后续需改进全量同步原子替换 |
| CMA 一单一库 | 可用 | 领域同步、机构比对、搜索和导出 | 与国家 CMA 完全独立 |
| 国家 CMA | **无限期暂停** | 只显示暂停公告；不订阅、不同步、不展示徽章 | 生产 Provider 禁用；写入/同步/徽章 API 返回 `NAT_CMA_SUSPENDED`；自动调度禁用 |
| 标准查新 | 可用 | 收藏/清单关注和周期检查 | 启动补跑 + 定时调度 |
| 多用户认证 | 未启用 | 当前为单用户 NAS / open_admin 模式 | 默认本机监听；外部部署使用 proxy token |

国家 CMA 的恢复条件见 [`ADR/0001-national-cma-indefinite-suspension.md`](ADR/0001-national-cma-indefinite-suspension.md)。
