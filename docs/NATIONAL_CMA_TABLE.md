# 国CMA 已批准表格库

固定主体：湖北省产品质量监督检验研究院。文件名称含“申请表”不改变本次数据已批准的事实；扩项、变更、保留等原始备注不解释为待批准状态。

## 管理与数据模型

资质查询页提供独立国CMA表格区。管理员上传 XLSX、预览告警后明确确认；确认新文件在一个事务中写入独立批次、能力行、标准关联并切换当前批次。重复 SHA-256 文件不重复写入，也不改变当前启用批次。历史版本启用操作支持显式回退。

独立 SQL 表：`nat_cma_table_batches`、`nat_cma_table_state`、`nat_cma_table_abilities`、`nat_cma_table_links`。旧 `nat_cma_*` 数据、采集和订阅不复用。保留 A:J 原始文本、工作表名、原始行号；签字人和身份证不进入能力记录或返回样例。工作簿本身不是数据库归档；原始文件仍应单独保存。

预览仅存内存，十分钟过期，最多四个准备中/已准备预览；重启后须重新上传。10MB 上传、100MB 总解压和 30000 行上限，ZIP 目录/实际解压长度验证。仅在内存中剔除无关且格式异常的 XLSX 核心元数据，无 Python 运行时依赖。

## 查询与匹配语义

查询按标准分组、每页 20 个标准；匹配关键词覆盖标准号/名称、大类、产品、参数、限制、备注，展开显示该标准的全部能力行。可用完整类别名称筛选。

徽章只匹配完整标准号含年版，支持 Unicode 斜杠、空白、年份前冒号等规范化，不匹配无年号或其他年版。一个单元格多个标准分别关联但仍保留原始能力行。未完整识别的附加内容保留并警告，该行不参与自动精确匹配，防止误报覆盖。`exactMatchAvailable` 表示该分组至少存在一行可自动匹配，`standardWarning` 标出需人工核对的能力行。

国CMA 命中仅代表当前表格列明的参数，并非整项/整标准覆盖；必须查看限制、备注。未命中仅代表本表没有该完整年版的可精确匹配记录，不推断其他来源的资质。CNAS、CMA、国家库、国CMA可同时展示。点击国CMA跳转本标准能力明细。

## API

接口前缀 `/api/nat-cma/table`，返回 `{data,error}`；读取遵循现有页面权限，写操作须管理员和现有 CSRF 校验。

| 方法/路径 | 用途 |
|---|---|
| GET /status | 固定机构、approved_table、当前批次与历史数量 |
| POST /preview | multipart 单文件字段 file；只预览不写库 |
| POST /confirm | JSON previewId、可选 name（最长120）；新批次原子启用 |
| GET /batches | 历史批次与 active 标记 |
| POST /activate | JSON batchId；明确启用/回退 |
| GET /search | q、limit、offset、可选 category；分组能力与原始行 |
| GET /abilities | stdCode；精确完整年版匹配的能力行 |
| POST /batch-match | JSON stdCodes（最多500）；匹配数量、限制提示与批次 |

前端徽章每100项请求，正/负缓存60秒，导入或切换版本后主动失效；传输错误不缓存为未命中。旧响应通过 generation 丢弃。
