# 游客只读与单管理员解锁方案

> 状态：方案已确认，尚未开始实施。
> 范围：游客 + 单管理员两种身份；暂不实现用户管理、多用户、注册、邀请和角色配置。

## 目标

游客无需登录即可使用公开查询能力，但只能查看，不能操作、修改或触发服务器副作用。管理员从右上角输入密码后，获得完整功能；退出或会话过期后立即恢复游客视图。

权限必须由后端路由强制执行，前端隐藏菜单只用于改善体验，不能作为安全边界。

## 身份模型

```text
guest  游客：公开查询、只读结果、只读预览
admin  管理员：游客全部能力 + 下载、同步、订阅、文件管理、导出、设置、运维
```

当前阶段不做用户管理，但保留现有 `users`、`sessions`、`userId`、`role` 和 `allowedTabs` 的扩展点，未来增加多用户时不重写业务路由。

## 游客公开范围

- 标准检索的公开搜索、详情和只读查询。
- 资质查询的公开结果查询。
- CMA 能力项目库的公开搜索和只读查询。
- 工具箱中的纯计算、纯解析、不会写数据库/文件/任务的功能。
- 公开健康检查的最小结果（仅 `ok` 和版本号）。

游客不可见且后端拒绝：

- 标准检索中的 Labr 补给。
- 本地文件库、服务器下载文件、下载历史中的敏感内容。
- 资质订阅、机构管理、关联、同步、同步日志和设置。
- CMA 一单一库的机构维度对比、机构列表、领域订阅与同步、映射、黑名单、诊断、重匹配、清理和导出。
- 工具箱中的查新写入、收藏修改、同步、补全写入、批量下载、服务器导出和高成本任务。
- 日志、统计、系统设置、诊断、主机信息、数据源内部状态和用户管理。

## 后端实施方案

### 1. 认证会话

- 恢复真正的 `guest/admin` 会话识别，不再给所有请求强制注入管理员。
- 管理员密码使用现有管理员记录的哈希，不保存明文。
- 登录成功后创建随机会话；数据库只保存会话哈希。
- Cookie 使用 `HttpOnly`、`SameSite`，HTTPS 时使用 `Secure`。
- 会话设置空闲/绝对过期时间，退出时删除服务端会话。
- 登录接口做失败限速和短暂封禁，错误信息不区分账号/密码。

接口：

```text
GET  /api/auth/status
POST /api/auth/login
POST /api/auth/logout
PUT  /api/auth/password
```

### 2. 权限守卫

保留并恢复以下边界：

- `requireAuth`：游客或管理员均可访问的公开接口。
- `requireAdmin`：仅管理员。
- `requireTab`：按身份检查页面能力。
- 必要时增加 `requireCapability`，表达 Labr、文件库写入、资质同步、CMA 机构比对等细粒度能力。

所有写入数据库、写文件、创建任务、远程同步、浏览器自动化、导出和高成本操作都必须使用管理员守卫。

### 3. CSRF 与限流

- Cookie 会话下所有 `POST/PUT/PATCH/DELETE` 写接口增加 CSRF Token。
- 同时校验 `Origin/Referer`，不能只依赖 SameSite。
- 登录、公开查询、高成本查询和管理员同步分别限流。
- 游客不能触发远程同步、OCR、浏览器自动化、PDF 生成或大批量导出。

## 路由权限矩阵

### 标准检索

游客可读：标准搜索、详情、公开文本和只读查询。

管理员专属：Labr 搜索/详情/健康状态/下载；标准下载、自动下载、批量下载、下载会话验证；会生成本地文件、缓存、任务或入库记录的预览操作；标准补全上传/写入、服务器导出；以及可能自动下载入库的 `POST /api/preview/request`。

### 资质查询

游客可读：公开 CNAS/CMA 结果、按标准查询和只读结果分页。

管理员专属：机构新增/删除/编辑、推荐订阅、机构关联、取消关联、同步、同步日志、设置和错误详情。

### CMA 一单一库

游客可读：不涉及订阅机构的能力项目库公开搜索。

管理员专属：机构维度对比、机构列表/详情、领域订阅与同步、同步进度、黑名单、手动映射、重匹配、诊断、清理和 Excel 导出。

`batch-status` 仅在确实只返回公开徽章信息时开放，并限制批量大小和频率。

### 工具箱和查新

游客仅可使用不产生副作用的解析/计算。管理员专属收藏修改、查新清单创建/重查/自动设置/导出/删除、批量下载、标准补全写入和所有服务器端任务。

### 文件库、任务和运维

本地文件列表、预览、下载、导入、删除、重命名、统一命名、预览缓存生成/重试、任务详情/SSE/取消、日志、统计、环境诊断、主机信息、源诊断、备份和设置全部管理员专属。公开 `/api/health` 只返回最小健康信息。

## 前端行为

游客侧栏/移动端仅显示：

```text
标准检索 · 资质查询 · CMA 一单一库 · 工具箱
```

并进一步隐藏标准检索中的 Labr、CMA 一单一库中的机构维度对比/领域订阅与同步、资质页管理操作、工具箱写入/同步/导出/高成本操作。

右上角用户菜单：游客显示“管理员登录”；管理员显示“退出管理员模式”和“修改密码”。登录成功后无需刷新即可更新导航和页面权限；退出或过期后清空管理员数据、停止 SSE/轮询并回到公开页。

## 明确不做

- 不做用户管理页面。
- 不做普通用户账号、注册、邀请和多管理员。
- 不做角色编辑、Tab 权限配置和用户级数据隔离。
- 不改变现有业务数据模型，除非会话实现确有必要。

## 验收标准

1. 游客无需登录即可查看四个公开模块。
2. 游客看不到 Labr、机构维度对比和领域订阅与同步。
3. 游客通过直接请求也无法新增、修改、删除、同步、导出或触发任务。
4. 管理员右上角输入密码后完整能力可用。
5. 管理员退出或会话过期后立即恢复游客权限。
6. 用户管理不在本阶段范围内。
